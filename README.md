## B.G.E.M. by [Audpocalypse](https://github.com/audpocalypse)
A small UI application to bulk generate and edit BGSM/BGEM material files.

[![.NET](https://github.com/Audpocalypse/B.G.E.M./actions/workflows/dotnet.yml/badge.svg)](https://github.com/Audpocalypse/B.G.E.M./actions/workflows/dotnet.yml)

Based off Material Editor 1.9.1 by [ousnius](https://github.com/ousnius).
Original decoding of version 2 files by [gibbed](https://github.com/gibbed) (rick 'at' gibbed 'dot' us).  
Additional work by [jonwd7](https://github.com/jonwd7) on version 20 and more.
